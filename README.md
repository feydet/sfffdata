#  [Проект 6: Сегментирование клиентов онлайн-магазина подарков. Задача: Произвести сегментацию клиентов на основе их покупательской способности, частоты совершения заказов и срока давности последнего заказа, а также определить оптимальную стратегию взаимодействия с ними]. Проект посвящен RFM-сегментации клиентов интернет-магазина на основе их покупательского поведения. В рамках работы была проведена очистка и предобработка данных о транзакциях, а также разведывательный анализ для выявления ключевых закономерностей. Основная часть проекта заключалась в построении и сравнении нескольких моделей кластеризации (K-Means, GMM, Agglomerative) для разделения клиентов на группы. Для повышения качества кластеризации применялись методы снижения размерности PCA и t-SNE, после чего были определены и интерпретированы профили полученных сегментов клиентов (https://github.com/feydet/sfffdata/blob/1868eb33bd40a11d2207a52b92d3e0a922dbc42d/PROJECTS/Project-6.%20%D0%9D%D0%BE%D1%83%D1%82%D0%B1%D1%83%D0%BA-%D1%88%D0%B0%D0%B1%D0%BB%D0%BE%D0%BD.ipynb)
